📖 คลังคำศัพท์ & ทฤษฎี Automation Integration

คู่มือความรู้พื้นฐานสำหรับนักเรียนมัธยมศึกษาในการเลือกใช้โปรโตคอลการสื่อสาร

⚡ Latency (ความหน่วงเวลา)

ระยะเวลาตั้งแต่ส่งข้อมูลจนถึงผู้รับ หากมีค่าต่ำ (Low Latency) ข้อมูลจะถึงทันที ซึ่งจำเป็นมากสำหรับระบบความปลอดภัย เช่น การกดปุ่ม Emergency Stop หรือการเบรกหลบสิ่งกีดขวาง

📶 Bandwidth (ความกว้างช่องสัญญาณ)

ปริมาณข้อมูลที่ส่งได้ต่อวินาที หากต้องส่งไฟล์รูปภาพ HD หรือแผนที่ 2D/3D LiDAR จะต้องใช้โปรโตคอลที่มี Bandwidth สูง เช่น Industrial Ethernet

🛡️ CAN Bus (Controller Area Network)

มาตรฐานการสื่อสารระดับฮาร์ดแวร์ในอุตสาหกรรมและยานยนต์ มีความทนทานสูง ป้องกันสัญญาณรบกวน เหมาะสำหรับการรับส่งคำสั่งควบคุมมอเตอร์และเบรกแบบ Real-time

📡 MQTT / Wi-Fi Protocol

โปรโตคอลการสื่อสารไร้สายแบบ Publish/Subscribe น้ำหนักเบา ทนต่อกรณีสัญญาณ Wi-Fi หลุดเป็นพักๆ เหมาะสำหรับหุ่นยนต์เคลื่อนที่ (AGV/AMR) ที่ส่งสถานะไปยัง Fleet Server

🌐 REST API & Industrial Ethernet

การเชื่อมต่อผ่านเครือข่ายความเร็วสูง เหมาะสำหรับส่งข้อมูลก้อนใหญ่ และเชื่อมต่อระหว่าง Fleet Server กับระบบฐานข้อมูลคลังสินค้าโรงงาน (WMS/ERP)

🏗️ Automation Pyramid (ปิรามิดระบบอัตโนมัติ)

การแบ่งชั้นของระบบอัตโนมัติจากชั้นล่างสุด (Field/Sensors) -> Control -> Fleet -> Enterprise (DB) การส่งข้อมูลข้ามชั้นต้องเลือกสายและโปรโตคอลให้เหมาะสม
